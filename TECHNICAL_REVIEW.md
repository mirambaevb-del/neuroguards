## Автоматические тесты

- **18 пройдены, 1 пропущен**: интеграционный тест настоящего EDF требует MNE и настоящие файлы CHB-MIT.
- Тесты используют синтетические массивы только для проверки программной логики. Они **не** подтверждают медицинскую эффективность.
- Отдельно проверены требования к размеру API-запроса и корректная сохранность неполного EEG-окна при потоковой передаче.

## Что не готово и почему

1. **Нет настоящих EDF и официальных `chbXX-summary.txt` в текущем окружении.** Реальный audit не выполнен.
2. **Нет подтверждённого набора независимых пациентов** с достаточным количеством приступов для train/validation/test.
3. **Нет обученной на EEG модели, ROC/PR-кривых, confusion matrix, event sensitivity и false alarms/hour.** Не выдумывать числа.
4. **Prediction за 10–30 минут не обучен.** Это научная гипотеза с подготовленной логикой исследовательской разметки, а не работающий сервис предупреждения.
5. **Lovable-сайт не подключён.** Есть backend API и инструкция по интеграции, но не подтверждён доступ к frontend/хостингу.

## Что можно честно показать экспертам уже сейчас

- Архитектуру `EDF → audit → preprocessing → features → model → API`.
- Примеры защиты от ошибочной разметки, утечки между пациентами и неверных единиц EEG.
- Реальный результат запуска программных тестов и поведение API без модели (`503`, а не выдуманный ответ).
- Ясную дорожную карту перехода от detection к prediction.

## Что нужно для полноценной демонстрации

1. Передать исходный `.ipynb`, доступные CHB-MIT `.edf` и соответствующие patient summary.
2. Запустить `python train.py --data /content/neuroguard_data --out /content/NeuroGuard_Final --train` в Colab после установки зависимостей.
3. Сохранить `results/dataset_audit.json`, `results/patient_split.json`, `results/rejected_windows.json`, `results/test_metrics.json`, реальные графики.
4. Провести обзор false negatives/false positives на независимых пациентах и проверку различий фильтрации.
5. Только после этого обсуждать научные выводы с жюри. Не показывать prediction как подтверждённую функциональность.
