# NeuroGuard — исследовательский AI-прототип

Версия: **0.2.0-research**. Это не медицинское устройство и не система экстренного оповещения.

## Что умеет эта версия

- Бинарная **детекция** по EEG: `INTERICTAL` (вне приступа) или `ICTAL` (приступ сейчас).
- Чтение CHB-MIT `.edf` через MNE и **обязательных** официальных `chbXX-summary.txt`.
- Проверка времени приступов относительно настоящей длительности EDF.
- Фиксированная схема восьми EEG-каналов: `FP1-F7`, `F7-T7`, `T7-P7`, `P7-O1`, `FP2-F8`, `F8-T8`, `T8-P8`, `P8-O2`.
- Окна 4 секунды без перекрытия; окна, пересекающие границы приступа, исключаются.
- Цифровой полосовой фильтр 0.5–40 Гц **на каждом окне одинаково при обучении и инференсе**. Это воспроизводимо, но создаёт пограничные артефакты; будущая версия может фильтровать непрерывные записи с контекстом.
- 20 признаков на канал (160 в сумме): статистические показатели, Hjorth, спектральные мощности и энтропия. Дублирование Hjorth Activity/variance устранено.
- Обучение двух базовых моделей: Random Forest и Logistic Regression. Logistic Regression включает `StandardScaler`, обучаемый **только** на обучающей выборке.
- Три непересекающиеся группы пациентов (train/validation/test) после аудита. При малом наборе это только ограниченный пилот; конкретный split записывается в `results/patient_split.json`. Выбор модели и параметров — по validation, тест не участвует.
- Метрики по окнам и событиям, включая sensitivity, false alarms/hour и задержку детекции.
- Сохранение модели, конфигурации каналов/фильтров и порядка признаков; FastAPI.
- Файл `prediction_research.py` для будущего изучения **прогноза** приступов за 10–30 минут, но **не обученный предиктор**. Отрицательные метки без достаточного будущего и непрерывной записи запрещены.
- Потоковый приём пакетов с сохранением неполного окна; каждый пакет обязан передавать `packet_start_seconds`. Разрывы, перекрытия и пакеты не по порядку отклоняются. Проверяются единицы `V` и целостность модели.

## Сейчас важно

В окружении, где создавался этот архив, **не было Colab-ноутбука, MNE и записей EEG**. Поэтому настоящий эксперимент **не проводился**, реальные метрики и файл обученной модели **не созданы**. Автотесты на синтетических массивах проверяют только корректность кода и API.

## Быстрый старт в Google Colab

1. Загрузите и распакуйте `NeuroGuard_Final.zip` так, чтобы папка располагалась в `/content/NeuroGuard_Final`.
2. Проверьте, что данные лежат в `/content/neuroguard_data` (или укажите свой путь):

   ```text
   /content/neuroguard_data/chb01/chb01-summary.txt
   /content/neuroguard_data/chb01/chb01_01.edf
   /content/neuroguard_data/chb01/chb01_03.edf
   /content/neuroguard_data/chb02/chb02-summary.txt
   /content/neuroguard_data/chb02/chb02_16.edf
   /content/neuroguard_data/chb03/chb03-summary.txt
   /content/neuroguard_data/chb03/chb03_01.edf
   ```

   Отдельные `.edf` без patient summary *не подходят*: нельзя доказать, что вся запись без приступов.
3. Откройте `NeuroGuard_AI_Final.ipynb` в Colab и запустите ячейки сверху вниз. Ноутбук проверяет наличие данных, обучает только при валидном audit и сохраняет результаты.

Или в терминале Colab:

```bash
cd /content/NeuroGuard_Final
python -m pip install -r requirements.txt
python train.py --data /content/neuroguard_data --out /content/NeuroGuard_Final
python train.py --data /content/neuroguard_data --out /content/NeuroGuard_Final --train
python -m unittest discover -s tests -v
```

Для тестов и скриптов понадобится рабочий каталог `NeuroGuard_Final` (для импортов). Программа не изменяет исходные EDF.

### Источник данных

Официальная база: [PhysioNet CHB-MIT](https://physionet.org/content/chbmit/1.0.0/), Guttag (2010), DOI [10.13026/C2K01R](https://doi.org/10.13026/C2K01R). Указаны версии и лицензия на сайте. Исходный набор большой (~42.6 GB); можно начинать с явно выбранных файлов трёх пациентов и **всех соответствующих summaries**.

## Запуск API после настоящего обучения

```bash
cd /content/NeuroGuard_Final
export NEUROGUARD_ALLOWED_ORIGINS=https://neuro-guard-monitor.lovable.app
export NEUROGUARD_API_KEY=replace_with_long_private_token
uvicorn api:app --host 0.0.0.0 --port 8000
```

Заголовок `X-API-Key` обязателен, если серверная переменная `NEUROGUARD_API_KEY` установлена. Не помещайте секрет в открытый JavaScript сайта: для production необходим серверный прокси/сессии. Colab не является надёжным постоянным хостингом.

### API

- `GET /health` — сервер отвечает, есть ли локальная модель.
- `GET /model-info` — описание настоящего обученного детектора или HTTP 503, если его нет.
- `POST /predict` — JSON с 8 каналами, `"unit": "V"`, измерениями **в вольтах** (`channels × samples`), частотой 256 Гц, длительностью, кратной 4 секундам. Максимальный JSON 4 MiB.
- `POST /predict-edf` — тело запроса: **сырые байты EDF** (`application/octet-stream`), не `multipart`. Ограничение размера 150 MiB, содержимое удаляется после обработки.

Пример POST (после реального обучения):

```json
{
  "channels": ["FP1-F7", "F7-T7", "T7-P7", "P7-O1", "FP2-F8", "F8-T8", "T8-P8", "P8-O2"],
  "sfreq": 256,
  "unit": "V",
  "start_seconds": 0,
  "samples": "8 rows × 1024 float values each; supply real EEG, not this string"
}
```

В ответе `seizure_score_uncalibrated` — **не калиброванная вероятность** и не медицинская достоверность. `calibrated_probability` пока `null`. Вся версия определяет текущий приступ, а не будущий.

## Ограничения

1. Пациентов мало. Результат на одном held-out пациенте не позволяет заявить обобщение на всех людей.
2. Тест CHB03 не используется для подбора параметров. Полная оценка потребует большего набора пациентов и нескольких независимых тестов.
3. EDF-записи могут включать артефакты, плохие каналы и разную конфигурацию. Несовместимые файлы отвергаются, а не автоматически подменяются другими каналами.
4. Частота 256 Гц должна совпадать. Автоматического ресемплинга нет.
5. Нет доказанной калибровки вероятностей. Нет реального real-time мониторинга, клинической валидации или тревожного сервиса.
6. Чтобы моделировать прогноз 10–30 минут заранее, требуются отдельная разметка *preictal*, непрерывный контекст, проверка ложных тревог и новый эксперимент; см. `prediction_research.py`.
7. Не загружайте личные медицинские EEG-данные на неподконтрольные сторонние сервисы.

## Воспроизводимость

- Фиксированное случайное число (`random_state=42`), фиксированные 8 каналов и порядок 160 признаков.
- Выделяется отдельная validation-группа пациентов; отбор модели только на ней. `results/test_metrics.json` сохраняет разовую оценку выбранной модели на независимом test.
- Версии Python/пакетов и железо проверяются в ноутбуке. Выводы зависят от фактически установленных версий (см. `requirements.txt`).
- Не заменяйте файлы `model/config.json` и `model/features.json` вручную.
- Файл модели `joblib` должен быть доверенным: его десериализация потенциально выполняет произвольный код.
